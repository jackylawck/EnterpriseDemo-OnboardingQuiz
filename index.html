📌 專案摘要 (Executive Summary)

企業級新員工入職培訓考核及問卷系統 (EnterpriseDemo) 是 ACME Corporation 示範智慧工地管治與人力資源數位化自主研發之無紙化解決方案，將傳統紙本考核與問卷全面轉型為雲端原生 Web 應用。結合動態防弊門禁、題庫隔離保護、向量 PDF 生成與 Python SMTP 後端傳輸，在無需依賴昂貴第三方雲端資料庫授權的前提下，直接達成「即時測驗 ➔ 自動評分 ➔ 滿意度採樣 ➔ 一鍵加密直送 HR 信箱」之端對端閉環。

🏛️ 流程生命週期與治理閉環 (Workflow Lifecycle)

為杜絕傳統紙本測驗「批改滯後、檔案易損毀、審計追蹤斷裂」等痛點，本系統建立標準四部曲受控管理機制：

第一階段・驗證
安全門禁通行
透過後端 Secrets 比對通行金鑰，阻斷未經授權之外界存取。
第二階段・考核
培訓知識測驗
評估規章制度與品質目標，提交即時計算得分與 75% 合格基準。
第三階段・調研
ESG 與滿意度評估
收集 1–5 分培訓滿意度、文康/義工活動偏好與開放式建設意見。
第四階段・閉環
受控生成與加密發送
動態合成受控 PDF (DEMO-HR-REC-V1)，TLS 直送 HR 信箱歸檔。

📋 業務受控標準對照表 (Governance Matrix)

階段 責任角色 系統實作機制 合規與審計依據
門禁核對 新入職員工 Secrets 安全隔離金鑰驗證 零信任存取控制與防作弊機制
第一部分：知識考核 新入職員工 規章與品質目標題庫動態評分 ISO 9001:2015 培訓成效驗收條款
第二部分：問卷調研 新入職員工 滿意度評估與文康活動需求收集 ISO 45001 職業健康及 ESG 員工關懷指標
第三部分：加密送出 後端自動化 Python SMTP (STARTTLS / Port 587) ISO/IEC 27001 傳輸加密與存取受限原則
受控檔案生成 系統引擎 生成標準 PDF (DEMO-HR-REC-V1) 落實資料最小化與受控文件宣告

⚙️ 技術亮點與資安架構 (Technical Implementation)

1. 零資料滯留 (Privacy-by-Design)

PDF 報告純於伺服器記憶體中動態生成，完成郵件傳輸即自 RAM 釋放，無持久化資料殘留風險。

2. 機密題庫後端隔離

題目與正確答案均嚴格封裝於 Streamlit Secrets，前端程式碼不暴露任何標準答案與敏感密鑰。

3. 後端 SMTP 全自動寄送

直連企業郵件伺服器，員工一鍵完成寄送並附帶受控 PDF，無需開啟本機郵件軟體。

4. 標準化時間戳記

全面校準系統時間戳記，產出標準化受控紀錄，滿足法定管理與內部審計規範。
